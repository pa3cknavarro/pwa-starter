Ecommerce Location API – Sample Pages

Interactive pages that call the vertical-slice Carter API. They demonstrate authentication via header, pagination, filtering, sorting, HATEOAS links, create/update/delete, and the consistent error envelope.

Sample Pages

  • Provinces – full CRUD + list with filter/sort/page
  • Cities – full CRUD + filter by province
  • Barangays – full CRUD + filter by province/city

How to use

  1. Start the API: dotnet run
  2. Open these pages from the same origin (they are served as static files).
  3. All requests automatically send X-Api-Key: demo-api-key-12345.
  4. Create operations also send a unique X-Idempotency-Key.

API endpoints used

  • GET/POST /api/v1/provinces · GET/PUT/DELETE /api/v1/provinces/{id}
  • GET/POST /api/v1/cities · GET/PUT/DELETE /api/v1/cities/{provinceId}/{cityId}
  • GET/POST /api/v1/barangays · GET/PUT/DELETE /api/v1/barangays/{provinceId}/{cityId}/{barangayId}

Swagger UI is also available at /swagger.
